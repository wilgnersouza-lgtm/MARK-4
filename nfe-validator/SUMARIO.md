## 🚀 COMO COMEÇAR

### ⚡ Opção 1: Docker (2 minutos)
```bash
git clone https://github.com/seu-usuario/nfe-validator.git
cd nfe-validator
docker-compose up -d
# Acesse: http://localhost:3000
```

### 🔧 Opção 2: Local (5 minutos)
```bash
# Terminal 1
cd backend && npm install && npm run dev

# Terminal 2  
cd frontend && npm install && npm start
```
